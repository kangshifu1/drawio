# Draw.io 页面树

## 目标与范围
在单个多页文件内，通过左侧树索引、搜索和管理页面。第一版交付本地网页版；不包含桌面安装包、跨文件工作区或多人协作。

## 设计
- 页面自身可作为父节点。保持原有页面名称、ID、图形和底部标签顺序。
- 在 `diagram` 元素上保存可选 `sheet-parent` 属性，值为父页面 ID。
- 工具栏最前面提供页面树图标。点击后在最左侧展开独立面板，图形库在其右侧。面板默认收起，支持关闭按钮和 Esc，提供搜索、展开折叠、当前页高亮、新建页面、新建子页面、重命名、上级选择与拖拽。
- 搜索保留匹配页面的祖先；删除父页后，直接子页显示为顶级，撤销删除可恢复层级。
- 拒绝自引用和循环；外部文件中存在无效父级或循环时，页面仍可从顶级访问，不自动改写原文件。
- 修改上级使用图模型的可撤销变更，触发修改状态和保存。新建子页沿用原有页面操作。
- 层级不依赖名称分隔符，也不依赖浏览器存储。折叠和搜索状态仅保留在当前会话。

## 接入
`SheetTree.js` 通过 `App.main` 完成回调挂载，适配默认打包资源及 `dev=1` 入口，无需重建原有压缩包。树内页面顺序跟随底部标签，可用原有页面排序操作调整。

页面面板作为独立网格列；图形库和其分隔条放在相对定位容器内，保留原生宽度拖动的坐标系。

## 验证
Node 测试覆盖层级、失效父级、循环和特殊 ID。Playwright 在真实 Draw.io 编辑器中验证切换、父级修改、保存重开、修改状态、撤销重做、搜索、折叠、新建子页、重命名、拖拽、删除父页与只读保护。
