# Page Tree Desktop · 页面树增强版 1（预发布）

**Draw.io 页面太多找不到？用一棵可搜索、可折叠的项目树组织多页图纸。**

这是基于 Draw.io 31.4.5 的个人维护版本，非官方发行，与官方无隶属或背书关系。适合多页面流程图、业务模块设计、MES 等项目文档的整理与导航。

## 更新内容

- 工具栏最前面新增“项目页面”图标，点击后在最左侧展开独立导航区域。
- 支持多级父子页面、展开／折叠、按名称搜索和点击跳转。
- 拖拽或通过下拉框调整父级，新增子页面及重命名。
- 父子关系随 `.drawio` 文件保存，支持相关操作的撤销／重做。
- 原有底部标签和元素选择区继续可用。
- 桌面版使用独立名称及图标，关闭官方自动更新。

## 验证与限制

- 页面树自动化测试、桌面上游 158 项测试通过。
- Mac arm64 包通过启动与页面树操作验证；Mac Intel 包在 Apple 芯片 Mac 上通过 Rosetta 验证。
- Windows 安装包已构建并检查完整性，**尚未 Windows 实机安装验证**。
- Mac 使用个人临时签名，未做 Apple 开发者签名／公证；Windows 未做发布者签名，安装时可能出现系统提示。校验值见附件 SHA256SUMS.txt。
- 暂不支持跨文件项目、纯目录节点或层级协作同步。
- 发布标签 `v31.4.5-page-tree.1` 表示首个定制迭代，应用基础版本号仍为 `31.4.5`。
