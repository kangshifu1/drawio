# Page Tree Desktop · 页面树删除版（预发布）

左侧“项目页面”面板新增 **删除页面**：选中页面后点击按钮，确认后删除该页及其图形内容。

- 删除父页时保留所有子页，直接子页移至顶级，其他下级结构保持。
- 删除页面与子页层级调整可一次撤销／重做。
- 至少保留一个页面；只读时禁用删除。
- 包含此前桌面保存、关闭启动顺序修复及打包隐私清理。
