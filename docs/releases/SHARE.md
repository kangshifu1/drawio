# 对外分享文案

Draw.io 的页面多了，底部标签很难找。我做了一个页面树增强版：点击工具栏图标，在最左侧展开独立的项目导航，把 sheet 按父子关系分层管理。

支持搜索定位、展开折叠、拖拽调整层级、新建子页面，层级随 .drawio 文件一起保存。原来的底部标签和元素选择区照常使用。

首个预发布版已提供 Mac Apple 芯片、Mac Intel 和 Windows 64 位安装包，也开放了修改源码及构建方法。

这是个人维护的非官方版本，安装包未做开发者证书签名／公证，Windows 尚未实机验证，欢迎试用并反馈。
