# Page Tree Desktop · Windows 关闭修复版（预发布）

针对点击窗口右上角关闭按钮无反应的反馈，修复一个桌面启动顺序缺陷：编辑器可能在桌面模块尚未就绪时创建，导致关闭消息的处理器没有注册，主进程一直等待回复。

## 修改

- 桌面模块及依赖脚本加载完成后才启动编辑器。
- 保留原生的未保存确认、保存后关闭和取消流程，不强制丢弃修改。
- 包含此前本地保存修复、页面树功能及打包隐私排除规则。

## 下载与安装

下载附件 `Page-Tree-Desktop-31.4.5-page-tree.3-windows-x64-setup.exe`。先保存图纸并退出旧应用，再安装覆盖。

本次只发布 Windows x64 安装包；[Mac 现有安装包仍在第 2 版](https://github.com/kangshifu1/drawio/releases/tag/v31.4.5-page-tree.2)。应用基础版本号仍为 31.4.5，请按安装包文件名中的 `page-tree.3` 确认本次版本。

## 验证范围

- 共 20 项 Node 回归测试通过，包含桌面脚本加载顺序的竞态测试。
- 共享桌面代码在 Mac 实际打包应用中通过连续保存与已保存文件原生关闭测试。
- Windows 安装包已重新构建，检查包内容、隐私排除和完整性；**尚无 Windows 实机验证**，因此不保证已覆盖所有关闭问题。若仍无法关闭，请反馈是否出现保存提示，以及“文件 → 退出”是否可用。
