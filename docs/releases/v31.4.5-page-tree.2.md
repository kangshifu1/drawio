# Page Tree Desktop · 本地保存修复版（预发布）

**修复打开本地 `.drawio` 文件后，每次保存都要求重新选择保存位置的问题。建议使用第一版的用户升级。**

## 修复内容

定制应用改名为 `Page Tree Desktop` 后，原有启动代码只识别 `draw.io` 的应用名称，导致未加载桌面文件读写逻辑，错误地走了网页版保存流程。

- 修正桌面环境识别，已有文件正常保存时直接写回原路径。
- 同步修正导出和 VSDX 导入入口的环境识别。
- 保留独立页面树、搜索、父子层级、拖拽整理等功能。
- 增加桌面识别测试及连续保存的真实应用回归检查。

## 验证与范围

- 页面树与桌面识别共 15 项 Node 测试通过。
- Mac arm64 打包应用已验证打开临时图纸、连续两次修改并写回同一文件，无需保存对话框。
- 三个平台包中的桌面识别修复均与提交源码核对；Mac Intel 和 Windows 本次重新构建。
- Windows 尚未实机运行验证，Mac Intel 尚未 Intel 实机验证。
- 个人非官方版本；Mac 临时签名，未做 Apple 开发者签名／公证，Windows 无发布者签名。安装可能出现系统提示。
